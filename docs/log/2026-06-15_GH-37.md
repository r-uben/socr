# GH-37 Decision Log — Add native-only CLI control

Date: 2026-06-15
Ticket: GH-37
Branch: feat/001-issue-plans

## What changed

Added `--native-only` as the positive counterpart to `--no-native-first`.

### Policy model (three states)

| Flags | native_first | native_only | Result |
|-------|-------------|-------------|--------|
| (default) | True | False | Clean BD pages: native. Enhancement pages (corrupt math): OCR. Scans: OCR. |
| `--native-only` | True | True | All BD pages (clean OR enhancement): native. Scans: OCR. |
| `--no-native-first` | False | * | All pages OCR'd (native_only is incoherent, ignored). |

### Files changed

- `src/socr/core/config.py`: Added `native_only: bool = False` field to `PipelineConfig` with full docstring; added `"native_only"` to `from_file` scalar_fields.
- `src/socr/cli.py`: Added `--native-only` to `common_options`; added `native_only` param to `build_config`; added incoherence warning when both `--native-only` and `--no-native-first` are passed (`--no-native-first` wins).
- `src/socr/core/born_digital.py`: Fixed pre-existing E741 lint errors (`l` -> `ln`) in `_detect_columnar_numbers`. No logic changes.
- `src/socr/pipeline/orchestrator.py`: Added `"native_only": cfg.native_only` to `_run_fingerprint` extra dict (invalidates resume cache on policy change). In `_backbone_native_first`, born-digital pages with `needs_ocr_enhancement` stay in `prose_pages` when `native_only=True`. In `_phase_agentic_routing`, added `native_only` to the `is_trusted_native` guard.
- `tests/test_orchestrator.py`: Added 11 new test methods across 3 classes: `TestNativeOnlyConfig`, `TestNativeOnlyFingerprint`, `TestNativeOnlyRouting`.

## Design decisions

- **Policy vs classifier**: GH-37 owns the user-facing policy; GH-35 owns the classifier (what makes a page `needs_ocr_enhancement=True`). These are kept separate: this change only routes differently depending on `native_only`, never changes what the detector returns.
- **Interaction with `--no-native-first`**: Incoherence is surfaced as a console warning; `--no-native-first` wins deterministically. No exception thrown — callers should continue.
- **Figure extraction**: Unaffected. `save_figures` / `describe_figures` run on the figure pass, which is separate from native-vs-OCR routing. Native-only does not force whole-page OCR before figure extraction.
- **Fingerprint**: Added to `_run_fingerprint` extra dict following the same pattern as `describe_figures` (GH-50). Toggling `--native-only` across runs produces different fingerprints, so the resume gate correctly reprocesses.
