## Deviation / design notes

One non-obvious pitfall: in the original `_phase_dual_pass_tables`, the
`fitz.open(pdf_path)` call was inside a `try/except Exception` that
swallowed `FileNotFoundError` (e.g. when tests use `/tmp/fake.pdf`).  After
extracting the helper, the `fitz.open` had moved into the method call but
outside the inner `try/except` inside the helper, so the exception
propagated to the caller. Fixed by wrapping the outer `with fitz.open` +
helper call in a `try/except Exception` in `_phase_dual_pass_tables`,
preserving the fail-open guarantee exactly.
