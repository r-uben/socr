# 2026-08-30 — TICKET-B1: the table judge ladder gate (GH-353)

## What changed

`src/socr/core/state.py`:
- Added `PageState.table_ladder_disposition: FailureMode | None = None` — the
  durable, pre-guard signal C3's manifest guard
  (`_apply_ladder_disposition_guard`) and C2's `_table_ladder_terminal`
  aggregation both read. No prior ticket added this field; every consumer
  used a defensive `getattr(p, "table_ladder_disposition", None)` because it
  didn't exist yet — C3's own decision log names B1 as the owner.

`src/socr/pipeline/orchestrator.py`:
- `_table_judge_prompt_digest()` — module-level, SHA-256 of the table-judge
  prompt policy file (`socr.judge.table_prompt.load_table_judge_prompt()`),
  read at call time, mirroring `_socr_source_digest()`'s pattern but kept
  uncached (the file is small, read once per document, and tests routinely
  monkeypatch the loader).
- `_run_fingerprint` gains a `# --- GH-353: table judge ladder ---` block:
  `table_judge_ladder`, and (only when the flag is on, else `None` so a
  cold document with the flag off doesn't get a spurious resume-invalidating
  key) `table_judge_rung1_model`, `table_judge_rung2_binary`,
  `table_judge_timeout_sec`, `table_judge_prompt_digest`. These were
  deferred from G1 explicitly for B1 to add.
- `UnifiedPipeline._build_table_judge_rungs()` — constructs the ladder's
  rung sequence once per document: `[]` when `table_judge_ladder` is off or
  `strict_local` is on (both rungs are cloud-only, so `strict_local` fails
  open rather than attempting egress); otherwise
  `[build_ollama_rung(rung1_model, rung1_host, timeout), make_gemini_rung(config)]`
  via lazy imports (no import-time dependency from `orchestrator.py` on
  `socr.judge.*`). Exists as its own method (not inlined in `_phase_agentic`)
  specifically so tests can `patch.object(pipeline, "_build_table_judge_rungs",
  return_value=[fake_rung])` without a live ollama daemon or `gemini` binary
  — the ticket's "injectable for tests" requirement.
- `UnifiedPipeline._run_table_judge_gate(state, page_num, ps, bo, rungs)` —
  the gate itself. Skips `engine == "chart_asset"` pages and pages with no
  text. Otherwise: `prepare_table_witnesses` (B0) → for each witness not
  `LOCATED` (MISSING/AMBIGUOUS), or when `rungs` is empty (the strict_local /
  flag-off-but-called fail-open case), synthesize
  `TableLadderResult(outcome=UNVERIFIED)` directly, no rung call attempted;
  otherwise `run_table_ladder` (A4) per witness, catching any exception from
  it (defensive: A4 is pure and shouldn't raise, but a rung's own bug must
  never crash the page) and treating it as UNVERIFIED too. A witness-prep
  exception (crop render failure, `prepare_table_witnesses` itself raising)
  is caught at the outer level and also demotes to UNVERIFIED — never
  propagated, never a silent pass. Emits one `AuditEvent` per table with
  `data={"table_id": witness.table_id}` (B2's per-table-only contract —
  never a page-wide accept with no `table_id`) using A1's
  `TABLE_LADDER_ACCEPTED_KIND`/`REJECTED_KIND`/`UNVERIFIED_KIND` constants.
  Reduces via A4's `reduce_page_ladder` and sets
  `ps.table_ladder_disposition` to `FailureMode.TABLE_REJECTED` /
  `TABLE_UNVERIFIED` / leaves it `None` on ACCEPTED — never touches
  `bo.audit_passed` or `bo.failure_mode` in place (the #252 round-1 rule:
  mutating a shipped attempt would make assemble discard the page's text).
- Wired into `_phase_agentic`: a doc-scoped `_table_judge_rungs =
  self._build_table_judge_rungs()` constructed once before the per-page
  loop (mirroring the existing doc-scoped equation-flags pattern), and a
  call `self._run_table_judge_gate(state, page_num, ps, bo, _table_judge_rungs)`
  immediately after `_guard_agentic_page_table_repetition` (so the judged
  table is the exact text that ships), gated on `self.config.table_judge_ladder`.
  Runs on native AND OCR pages alike — the gate call sits in the fused
  per-page loop after the native/OCR branches have already converged on a
  single `bo`, so there is no separate "native lane" code path to exempt.
  Per #363's scope pin, this call site lives ONLY in `_phase_agentic` —
  non-agentic paths are out of scope for this epic.

## Contract compliance (binding rulings from prior tickets)

- **C2/C3 disposition contract**: `PageState.table_ladder_disposition` is
  set, never `audit_passed` flipped, never `best_output` mutated in place.
  Verified by the `test_flag_off_vs_on_with_rejecting_ladder` /
  `test_native_lane_is_witnessed_too` tests reading `result.status` /
  `result.error` (the C2-established surface), not a per-page field on
  `EngineResult.pages` (which is a single document-level aggregate,
  `page_num=0` — not a per-page list; confirmed by reading
  `_phase_assemble`'s `EngineResult(...)` construction directly rather than
  assuming a per-page list existed).
- **B2 per-table emission**: every audit event carries
  `data={"table_id": ...}`; no page-wide accept without a `table_id` is ever
  emitted (there is no path in the gate that emits an event without a
  witness's own `table_id`).
- **Witness fail-open**: AMBIGUOUS/MISSING → UNVERIFIED, never silent pass,
  never an exception. `chart_asset` pages skip entirely. Any infra error
  (crop render, witness-prep exception, rung construction, `run_table_ladder`
  raising) → UNVERIFIED.
- **#363 scope pin** (post-merge leftover, read during this session):
  agentic-only choke, `chart_asset` skip, non-agentic out of scope — matches
  what was already implemented; no rework needed.
- **Cascade-halt isolation**: the gate never touches `decision.attempts` /
  `route_page` internals — only `state.events` (via `AuditEvent`) and
  `ps.table_ladder_disposition`, entirely separate from the
  `"timeout" in (att.reason or "")` substring check that drives cascade-halt.
- **`--strict-local` + ladder**: `_build_table_judge_rungs()` returns `[]`
  when `strict_local` is on, and the gate treats an empty `rungs` list as an
  explicit fail-open signal — every table page becomes UNVERIFIED with zero
  attempted egress, matching G1's documented interaction.

## Tests

New: `tests/test_table_judge_gate.py` — 19 tests, fully hermetic (every rung
is an injected `_QueueRung` fake; `_build_table_judge_rungs` is overridden in
every `process()`-level test; `_available_engines_for_agentic` and
`_resolve_judge_model` both patched). Groups:
- `TestBuildRungs` (3): flag off → `[]`; `strict_local` + flag on → `[]`;
  flag on + not `strict_local` → 2 real (but I/O-free at construction time)
  rung callables.
- `TestGateSkipRules` (2): `chart_asset` engine and empty text both skip
  entirely, asserted by making `prepare_table_witnesses` itself raise on
  call — proving the gate returns before ever reaching it.
- `TestWitnessFailOpen` (4): borderless page (0 boxes → MISSING) → UNVERIFIED,
  rung never called; two-table markdown against one ruled box (count
  mismatch → AMBIGUOUS) → both blocks independently UNVERIFIED; witness-prep
  raising → UNVERIFIED, not propagated; empty `rungs` list → UNVERIFIED, no
  call attempted.
- `TestRungFailOpen` (4): parametrized over missing-binary / HTTP-error /
  parser-error `RungResult(ok=False)` shapes (all collapse to the same
  contract per A1) → UNVERIFIED; `run_table_ladder` itself raising →
  UNVERIFIED, not propagated.
- `TestLadderOutcomes` (3): ACCEPTED → no disposition set, `accepted` event
  with `table_id`; REJECTED → `TABLE_REJECTED` disposition, `rejected` event;
  two witnesses on one page, one REJECTED one UNVERIFIED (via a stubbed
  `prepare_table_witnesses` context manager) → page disposition is
  `TABLE_REJECTED` (A4's "any REJECTED wins" rule), both event kinds present.
- `TestProcessFlagDifference` (3), the ticket-mandated full `process()`
  tests, each running the pipeline against a real (fitz-built) ruled-table
  PDF:
  - `test_flag_off_vs_on_with_rejecting_ladder`: two separate `process()`
    calls (flag off with no ladder override; flag on with
    `_build_table_judge_rungs` overridden to a rejecting fake), asserting
    the DIFFERENCE per the #253/#257 trap — flag-off ships `SUCCESS` with no
    `table_rejected` text; flag-on demotes to `AUDIT_FAILED` with
    `table_rejected` in `result.error` (the C2-established surface).
  - `test_native_lane_is_witnessed_too` (the former F1 shape): a
    `bd_detector` mock reporting a born-digital page with `has_tables=True`
    and the same table markdown as its native text, ladder rejecting →
    demoted exactly like the OCR case, proving the native lane is not
    exempt from the gate.
  - `test_flag_off_makes_zero_witness_calls` (sentinel): flag off, with
    `prepare_table_witnesses` patched to raise on any call → `process()`
    still returns `SUCCESS`, proving the gate is never entered at all when
    the flag is off (not merely a no-op inside the gate).

Two early test-writing mistakes, fixed during this session (not deviations
from the ticket, just bugs in my own first draft):

- `_ruled_pdf`/`_borderless_pdf` didn't `mkdir` their parent when called with
  a nested `tmp_path / "off"` style path (the flag-comparison test needs two
  independent PDFs). Fixed by adding `tmp_path.mkdir(parents=True,
  exist_ok=True)`.

  (`page_num=0`, built in `_phase_assemble`), not a per-page list — confirmed
  by reading the `EngineResult(...)` construction directly. Fixed to assert

  `tests/test_ladder_status_surfacing.py` (C2) already established.
