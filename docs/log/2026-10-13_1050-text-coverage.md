Worktree `impl/issue-1050`. Step 1 only: make the loss visible. No model
call, no OCR of crops.

## Which seat

Fable. Hand-check on silent-SUCCESS flags: 53/60 pages (88%) had some
real uncovered text; 237/295 regions (80%) were citable. Astra's region
precision was 41%. Wonder's success-stratum region precision was 80–94%

## The check

`core/text_coverage.py`. Render at `DETECT_DPI` (150). Adaptive-mean ink
(block 15, offset 2), 8-connected components. Covered if ≥ half the
pixels sit under a #1099 visible char box (`rawdict` chars, span alpha ≠
0). Residual glyph-like components form rows; rows that look like real
text (corpus envelope) become regions.

Constants, all named for the percentile they are:

| name | value | derivation |
| --- | --- | --- |
| `GLYPH_H_P02_PX` | 2 | covered-glyph height p2 |
| `GLYPH_H_P50_PX` | 12 | median covered-glyph height |
| `GLYPH_H_P98_PX` | 19 | covered-glyph height p98 |
| `GLYPH_W_P02_PX` | 3 | covered-glyph width p2 |
| `WORD_W_P50_PX` | 48 | median native word width |
| `WORD_W_P98_PX` | 135 | a residual blob may be a blurred word |
| `LETTER_H_PX` | 6 | valley between punctuation mode (3 px) and letter mode (12 px) |
| `ROW_FILL_P01` | 0.327 | real text-row median fill, p1 |
| `ROW_FILL_P99` | 0.917 | p99; solids sit at 1.0 |
| `ROW_H_RATIO_P99` | 1.438 | row-box height / tallest glyph, p99 |
| `ROW_CV_W_P01` | 0.120 | width coefficient of variation, p1 |
| `_MIN_FILL_FRAC` | 0.55 | copied from `image_locate` (layering forbids a private import) |
| `_MAX_THICK_PT` | 2.0 | same |
| `REPEAT_BIN_PT` | 11.52 | two median glyphs in PDF points (`2 * 12 * 72 / 150`) |
| `REPEAT_SHARE` | 0.5 | "most pages" = more than half |

## Furniture

Repeat-ink: a quantized bbox that appears on more than half the
document's pages, and on at least two. Header/footer *band* is recorded
on the region but is not a kill (Round 2): figure labels sit above the
caption. The r1 measure reported "no page flagged only by furniture"
because `suppress_document_furniture` mutates in place and `verdict_raw`
was read after the kill.

## Verdict

- `passed` / `flagged` / `unknown` in the sidecar (`text_coverage`), on
  `PageState`, in document `metadata.json` (`text_coverage_pages`), and
  as a CLI yellow line.
- Flagged: native text unchanged, WARNING, `TEXT_INK_UNREAD`. Not
  `FIGURE_WORDS_UNREAD`: the seats' hits sit outside #1053 figure crops.
  Region PNGs under `figures/uncovered_text_pN_rI.png`. Mark:
  `[page N: uncovered text — see image]`, same shape as #1048.
- Unknown: render/analysis exception. Target 4 fail-closed: the page
  does not ship SUCCESS. Step 1 does not call a model; whole-page
  escalation is step 2. WARNING + `TEXT_COVERAGE_UNKNOWN`.

## Resume / fingerprint / byte identity

Unflagged pages stay byte-identical to the check-off baseline. The
fingerprint includes `check_text_coverage`, so a run that turns the
check on cannot skip a previously-SUCCESS page that this build would
flag. WARNING pages are not resume-skippable (existing ledger rule);
the check re-runs and re-applies the mark on fresh native extract.

hand-labelled in this pass beyond the seats' existing sets. One corpus,
one run (22922695).

## Round 3

Astra review: do not merge. Six reproduced findings.

### P0 — repetition

Furniture is no longer position-only. A region is dropped only when the
same rendered pixels sit at the same quantized place on most pages *and*
those pages do not share one text-layer fingerprint. Three copies of
Golosov p32 keep their flags. A header logo on otherwise different pages
is still dropped. When in doubt, keep the flag.

`COVER_MAJORITY`, `ROW_CV_MIN_MEMBERS`, `REPEAT_SHARE`, `REPEAT_MIN_PAGES`
are design choices, not measured optima. `H_MED_MIN_COVERED = 20` is the
named sample-size floor that was the bare `>=20`: below it we use the
corpus median glyph height.

### P0 — rotation

Grouping runs horizontally and vertically. A raster label that flags at
0° also flags at 90/180/270. Crops use the same pixmap transform as
analysis (`_to_pix`); the 180° crop is no longer white. Rotation is
handled; we do not return `passed` for a rotated miss.

### P1 — equations

`_decorate_coverage_winner` stamps the coverage mark on the winning
attempt and keeps `corrupt_math_hybrid` pointing at that same object.
Selection still ships the recovered equation plus the mark.

### P1 — chart pages

`chart_asset` is a native-text lane (`_NATIVE_TEXT_LANES`). Apply, the
document bucket, the marker and the CLI use the same
`startswith(("native", "chart_asset"))` gate. A flagged chart page is
WARNING at every level, not page-WARNING / document-SUCCESS.

### P1 — production measure

`_prepare_text_coverage` analyses every page of the PDF (furniture
denominator is the document). Apply still only demotes `native*` /
`chart_asset` winners. Non-native pages should be analysed for that

## Round 4

Astra review 2: do not merge. Four findings, all pinned.

### P0 — repetition

Repeated ink is furniture only when the region lies entirely outside
the document text body. The body is the median of each page's visible
char y-span (`#1099` boxes, PDF space): typical first-line / last-line.
A region is in a header/footer margin iff its box is wholly above that
top or wholly below that bottom. Distinct captions (`Appendix 1/2/3`
on three Golosov-shaped copies) no longer suppress axis titles. A
header logo still drops.

Cost vs r3 (`compare_r3_r4.json`, same 17,091 pages): +190 flags
(183 unlabelled, 7 Fable `t`); −6 flags (5 unlabelled, 1 Fable `t`).
No labelled citable page (`T`) went flagged → passed. Fable 28/28
held; Astra 42/45 same misses; Wonder 26/33 (gained Stock–Watson EJ
p30). Silent native flags 1,067 → 1,122. Extra flags are unneeded
warnings; that is the acceptable side of #1130.

### P0 — rotation

Glyph envelope now filters `min(w,h)` / `max(w,h)` so page.rotation
does not swap a letter out of the band. A 16 pt Helvetica-Oblique
“Minimum wage and employment” raster (12 pt tall on the page) flags
at 0/90/180/270.

### P1 — crop write

`cv2.imwrite` returning False raises; apply surfaces `unknown` and
does not claim “see image”.

### P1 — chart document

`test_chart_asset_flag_demotes_document` runs `process()` with the
page forced onto the chart lane and asserts document `AUDIT_FAILED`.
A mutant that restores `startswith("native")` on the assemble bucket
fails it.

## Round 5

Astra review 3: do not merge. Repeat-ink failed a third time; the
native-table fallback re-stamped SUCCESS.

### P0 — suppression removed

`suppress_document_furniture` and the `REPEAT_*` constants are gone.
`coverage_for_document` is `analyze_page` per page. A logo flagged by
mistake is an unneeded warning; a label suppressed by mistake is silent
loss. The furniture measurements in Rounds 1–4 stay as history.

Astra's three-page raster-above-distinct-captions case is a `process()`
test. It used to ship page and document SUCCESS because the median
caption span made the figure a header.

Cost vs r4 (same 17,091 pages, `compare_r4_r5.json`): **0 extra flags,
0 lost**. The r4 body-margin rule was already keeping every corpus
region that `analyze_page` found. The three-page caption attack is not
in the corpus as a document. Recall unchanged: Fable 28/28, Astra
42/45, Wonder 26/33. Silent native flags still 1,122 (28 T, 24 t, 5 F).

### P1 — native-table fallback

A structure-class page skips the passing-best_output short-circuit and
lands on the native fallback, which rebuilt `SUCCESS/NONE` from
`native_text`. The fallback now ORs `coverage_unread` into
`native_demoted`, ships WARNING plus the mark (flagged) or
`TEXT_COVERAGE_UNKNOWN` (unknown). Pinned through `process()` in
default and `native_only`.

### P1 — cluster wall (no code change)

Astra treated the check as serial (~99 docs/quarter × 20–35 s =
33–58 min). The cluster runs 16 `socr batch` workers per GPU, so that
CPU volume divides across 16 processes.

From our numbers, added wall per quarter ≈ `99 × seconds_per_doc / 16`:

| seconds/doc | source | added wall / quarter |
| --- | --- | ---: |
| 3.5 s | r3 idle median | 22 s |
| 4.3 s | r5 idle median | 27 s |
| 13–18 s | idle watch docs | 1.3–1.8 min |
| 20–35 s | Astra's serial inputs | 2.1–3.6 min |

The 33–58 min figure is the serial sum, not cluster wall. This will be
measured in the next cluster run.
