# #1053 first slice: raster figure crops, single column

Branch `fix/issue-1053` off origin/main a257fd1d. Spec: `2026-10-10_1053-figure-crops-design.md`
("Smallest first PR"). Uncommitted at hand-off.

## What changed

- `figures/extractor.py`: `figure_boxes(page)`, raster half. One box per DRAWN placement
  (`get_image_info(xrefs=True)`, the #1059 reader), same gates as `has_chart_marks` (placed area
  >= `CHART_MIN_CLUSTER_AREA`, not a scan/decorative page image, GH-511/656). `[]` = none, `None`
  = unknown (xref 0 or a lookup failure). The vector tail of `has_chart_marks` moved verbatim into
  `_vector_chart_found`; `has_chart_marks` ends `return _vector_chart_found(page)` and is otherwise
  untouched.
- `figures/figure_crops.py` (new): `plan_figure_page` returns a `FigurePlan` (boxes, word-to-owner
  map prose / caption / `figure:i`, each figure's own native lines) or `None` to keep the
  whole-page route. Declines on: no box, unknown box, rotated page, a vector chart (or any
  `chart_region_bboxes`), or a layout that is not clearly one column.
- Single column: nothing in the codebase answers it (`_detect_column_gutter` is blind to a
  spanning title; `_estimate_columns` uses a 15% constant). `is_single_column` and `is_in_reading_order` (the interleaver walks blocks in stream order and
  emits a crop before the first block at or below it, so a stream that writes a lower block first
  declines the page; furniture blocks skipped as the interleaver does). Single column = no two text
  blocks / figure boxes sit beside each other (disjoint in x, overlapping in y by more than
  `born_digital._REGION_COVERAGE_DROP`). No new constant. It fails closed (a right-aligned page
  number level with a heading declines the page).
- `orchestrator._figure_crop_body`, called first in `_agentic_chart_asset_page`: renders each crop
  with the existing `_render_chart_region_crops`, builds one `(rect, placeholder)` region per box
  and runs the page through `interleave_table_regions_into_page(..., suppress_represented=False)`
  (new keyword-only parameter, default True keeps the table paths byte-identical). Round 1
  (Astra): the "already represented" suppression is a bag-of-tokens presence test, so with figure
  lines in the region a straddling `10 10` lost a `10` and a placeholder token could eat a tick
  label. Suppression is now off for figures: every native word ships exactly once, in stream
  order, words inside a box right after its crop. Crop files and placeholders use the `chart_region_pP_N` names the
  rendering machinery already emits. No whole-page PNG on this route. Any render failure returns
  `None` and the old route runs.
- Status: a figure with no native word inside -> page WARNING, new `FailureMode.FIGURE_WORDS_UNREAD`
  (`core/result.py`), `PageState.figure_words_unread`, `figure_words_unread_suspect` (manifest),
  in-place demotion of a SUCCESS chart/native winner in `_winning_page_output`, document term
  `figure_unread_pages` in `pages_ok` + the "any defect" condition + event
  `figure_words_unread_retained` + console line, page event `figure_crops` (counts by owner).
  `audit_passed` is never touched. `docs/OUTPUT.md` updated (34 members, two events).

## Left out on purpose

- Vector figures, `has_chart_marks = bool(figure_boxes)`, panel merging (one box per placement; a
  side-by-side pair of panels is two boxes beside each other, so the page is declined), multi-column
  pages, Tesseract, any model, the caption<->crop identity check, a digit comparison.
- Native words inside a box are trusted as exact and not flagged: no witness exists yet to say the
  pixels hold more. A text-free photograph is flagged (over-flagging, unmeasured on the corpus).
- Boundary: nothing is deleted or duplicated any more; a line straddling a box edge ships whole
  in the prose (the owner map still counts its inside words for the "unread" decision only).
- Resume: a WARNING page is never restored from the per-page ledger (verified by test), so the
  flag is recomputed each run and is not persisted in the ledger meta. The no-`best_output`
  synthetic native fallback in the manifest is not given the mode: the chart lane always sets a
  `best_output`.
- `figure_boxes` re-implements the raster gating of `has_chart_marks` rather than sharing it
  (the spec said leave `has_chart_marks` unchanged); drift is possible until the vector half
  lands and `has_chart_marks` becomes `bool(figure_boxes(page))`.
