# GH-34 — Recovered-to-empty must not count as recovered

Date: 2026-06-15
Agent: socr-implementer (claude-sonnet-4-6)
Consilium decision id: 20260615T094741Z-2940 (Codex + Gemini converged on Option C)

## What changed

Two surgical guards added; no new abstractions or manifest fields.

### src/socr/core/state.py — `DocumentState.apply_result`

Added a non-empty text predicate to the promotion condition (same
`text and text.strip()` idiom already used by `PageState.best_attempt`).

Before:
```python
if page_out.audit_passed and (
    not page_state.best_output or not page_state.best_output.audit_passed
):
    page_state.best_output = page_out
```

After:
```python
if (
    page_out.audit_passed
    and page_out.text
    and page_out.text.strip()
    and (not page_state.best_output or not page_state.best_output.audit_passed)
):
    page_state.best_output = page_out
```

An empty-but-audit_passed repair can no longer overwrite a non-empty
prior best_output, and can never become best_output on its own.

### src/socr/core/audit_log.py — `_derive_escalations`

Added a guard on the next attempt before emitting `recovered_by`.

Before:
```python
took_over = attempts[i + 1].engine if i + 1 < len(attempts) else ""
if not took_over:
    continue
```

After:
```python
next_attempt = attempts[i + 1] if i + 1 < len(attempts) else None
if not next_attempt or not (next_attempt.text and next_attempt.text.strip()):
    continue
took_over = next_attempt.engine
```

An empty successor never generates a misleading `recovered_by` event.

## All-empty case verification

`_winning_page_output` in manifest.py already handles `best_output is None`
correctly: it falls through to `p.best_attempt` (which also filters for
non-empty text via the same predicate), and if that is also None, returns
an explicit `page_failed_marker`. No changes needed in manifest.py.
