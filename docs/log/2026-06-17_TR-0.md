## `assert_table_parity` mismatch reporting

The helper accumulates ALL errors before raising `ParityError` (not first-fail). Error codes:
- `SEPARATE-GRIDS` — fewer than N separate markdown tables found.
- `TABLE-MISSING` — no grid contains any expected row label.
- `ROW-MISSING` — a row label not in the matched grid.
- `COL-MISSING` — a column header not in the matched header row.
- `CELL-MISSING` — row has too few cells (ragged).
- `CELL-MISMATCH` — actual value differs from expected (includes `na` vs filled).
- `CHART-NO-IMAGE-REF` — no `![…](…)` image reference in the markdown.
- `PROSE-MISSING` — expected prose keywords not found outside table blocks.
- `READING-ORDER` — a later region appears before an earlier one in the markdown.
