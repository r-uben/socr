# #1098 — a `|` inside LaTeX maths must never form a Markdown table

Worktree `fix/issue-1098`. Scoped to the scanned-page source-evidence
check (`collect_table_tokens` / `verify_scanned_table`).

## Callers of `find_table_blocks`

`find_table_blocks` (in `src/socr/tables/reconcile.py`) groups any two
consecutive pipe-bearing lines. It is shared: header repair, ditto,
orchestrator, agentic, manifest, state, structure_check, page_credential,
chart_regions, witness, crop_repair, and the native-prose floor. Changing
it would drop informal pipe grids those callers still splice and repair.

`table_syntax_line_indices` already requires a `|---|` for *native* text
withholding (#649). The source-evidence check was still using the loose
finder, so `$P(A|B)$` on two lines became a table and failed the page on
unsupported LaTeX labels (`cdot`, `mathbf`, `frac`, …).

`find_table_blocks` itself is untouched. No other caller is edited.

## Rule (round 4)

Page-level masking (`_hide_maths_pipes`) is gone. `find_table_blocks`
runs on the original markdown. A found block is a phantom (excluded)
only if both:

- (a) it has no `|---|` separator row, and
- (b) on every non-separator line, every `|` is maths-local on that
  same line: `\|` only when preceded by an odd number of backslashes,
  plus `\left|` / `\right|` / `\vert` / `\mid`, or inside a same-line
  `$…$` pair whose interior has a letter or a backslash command.
  Digits / spaces / punctuation only (currency, compact or spaced)
  never hide a pipe. The old ` | ` special case is gone.

No multi-line spans, environments, or display-block tracking. A
separator keeps the block even when the data rows look like `$P(A|B)$`.
Every other block is judged exactly as on origin/main.

Round 2's page-level hide was fail-open: `$29.99` opened a span to the
next `$`/EOL; an unclosed `\(`/`$$`/`\begin{align}` (or a paired `$$`
around a table) hid every later pipe; `\begin{center}` hid a table
inside it.

## Measurement

181 pages from `witness_detail_out.json`, types from
`pagetype/labels.json`. Stored `witness_texts` stand in for Tesseract.
Before = `collect_table_tokens` via raw `find_table_blocks`. After =
`_evidence_table_blocks`. Verdict = `verify_table_tokens` on the
witness bundle, or pass when there are no blocks.

Round 4 (same as round 3 on this sample):

- 8 / 16 `maths/prose, no table` pages fail before and **pass after**.
- 8 / 16 still fail (display / `align` / `array` conditioning bars
  with no same-line `$…$`): Caballero–Simsek AER 2022 pp. 62, 67, 68;
  Caballero–Simsek WP 2022a pp. 63, 69; Pastor–Veronesi AER 2009 p. 44;
  Stephens–Donnelly JRSSB 2000 pp. 10, 35.
- 0 / 144 `table` / `table + figure` pages change verdict.

Round 2 had rescued all 16 (page-level hide covered display maths) and
also 0 table flips.
