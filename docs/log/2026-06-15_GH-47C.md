## Summary

Implements Option C (log-only, no automated warning, no caption comparison, no threshold)
as decided by the `/consilium` panel. Two structured changes:

1. **bbox persistence** (step-0 precondition) — the figure bounding rect was computed in
   all three extraction strategies but silently discarded. Now persisted on `ExtractedFigure`
   and carried through to `FigureInfo`.
2. **Recoverable-label audit event** — for each DESCRIBED figure whose `bbox` is not `None`,
   the orchestrator opens the PDF, calls `page.get_text("words")`, and filters word tokens
   whose centre-point falls inside the figure rect. The result is appended to `state.events`
   as `AuditEvent(kind="figure_recoverable_labels")` with structured `data` including
   `recoverable_labels`, `inapplicable`, and `bbox`. A figure region with zero recoverable
   words is inapplicable (rasterized/embedded image) — always recorded as an empty set,
   never a failure. No caption is modified.

## Where bbox is persisted

- `src/socr/figures/extractor.py`: `ExtractedFigure.bbox: tuple[float,float,float,float] | None`
  field added (defaults `None`). Set at three creation sites:
  - **Strategy 0** (vector cluster): `(x0, y0, x1, y1)` from the cluster bbox.
  - **Strategy 0 presentation fallback** (landscape): computed from `page_width/height` fractions.
  - **Strategy 1** (IMAGE block): `(x0, y0, x1, y1)` from the block `bbox`.
  - **Strategy 2** (xref image): first `placement_rects[0]` as `(r.x0, r.y0, r.x1, r.y1)`;
    `None` when no placement rect is available.
- `src/socr/core/result.py`: `FigureInfo.bbox` field added with `to_dict` (serialises as list)
  and `from_dict` round-trip. `None` serialises to JSON `null` and round-trips cleanly.

## Where the recoverable-label set is recorded

- `src/socr/pipeline/orchestrator.py`: new method `_record_figure_recoverable_labels(state, fig_info)`.
  Called in the per-figure loop of `_describe_and_embed_figures`, gated by `was_described and fig.bbox is not None`.
  Emits `AuditEvent(kind="figure_recoverable_labels")` into `state.events` (same path as
  `figure_cap_reached`, GH-47A). The `data` dict contains:
  - `figure_num`: int
  - `recoverable_labels`: list[str] (empty for raster figures)
  - `inapplicable`: bool (True when empty)
  - `bbox`: list[float] — the figure rect used for filtering

## Design constraints honoured

- No caption rewritten anywhere in this path (hard AC).
- No magic thresholds introduced.
- Deterministic — no model calls.
- Zero recoverable words → inapplicable, recorded as empty set, never fail.
- `was_described` gate ensures undescribed figures produce no audit noise.
- `bbox is None` guard ensures xref images without placement rects are silently skipped.
- Model reference not touched (local model = qwen3-vl:30b-a3b-instruct throughout).

## Residual risks

- Strategy 2 xref images without placement rects have `bbox=None` and are skipped by
  the label-recovery path. This is expected and correct: we cannot localise them on the
  page, so there is no region to filter words by.
- The centre-point containment filter may miss labels that straddle the exact edge of the
  bbox. This is a conservative choice (avoids picking up caption text just below the figure);
  if edge labels matter in a future corpus, the filter can be relaxed to rect-intersection
  without any interface change.
- `fitz.open()` is called once per described figure (not batched per page). For documents
  with many described figures per page, this could be optimised by a page-handle cache, but
  the overhead is negligible for the expected corpus size (few described figures per run).
