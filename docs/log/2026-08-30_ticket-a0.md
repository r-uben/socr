# TICKET-A0 — table judge prompt policy file (GH-353)

## What changed
- `src/socr/prompts/table_judge.md`: the table-judge prompt template. Six-code
  closed finding enum (`MISSING_VALUE`, `FABRICATED_VALUE`, `WRONG_BINDING`,
  `HEADER_MANGLED`, `STRUCTURE_MERGED`, `NOT_A_TABLE`) verbatim, "judge only the
  table region" scoping instruction, an explicit empty-cell rule (a genuinely
  blank cell in both image and markdown is not a finding — only a value visible
  in the image and absent from the markdown is `MISSING_VALUE`), and two
  injection placeholders: `{{PRIOR_FINDINGS}}` (tiebreak mode) and
  `{{EMITTED_MARKDOWN}}`.
- `src/socr/judge/table_prompt.py`: `load_table_judge_prompt()` (raw template,
  mirrors `socr.judge.judge.load_judge_prompt`) and
  `build_table_judge_prompt(markdown, prior_findings=None)` — renders the
  template with the emitted markdown and, when a prior rung FAILed and a later
  rung is confirming, the prior findings; absent/empty findings render a neutral
  first-rung note rather than leaving the slot blank.
- `tests/test_table_prompt.py`: 9 tests covering the six codes present verbatim,
  schema markers present, "table region" / empty-cell wording present, raw
  loader vs rendered output, findings injection (present and absent/empty
  cases), and missing-key tolerance in a findings payload.

## Design notes
- Started from the bake-off prompt used in the GH-356 winning run
  (`~/tmp/socr-356-bakeoff/judge_prompt.txt`, not committed) and extended it
  with the scoping/empty-cell instructions A0's ticket calls for, plus the
  tiebreak injection slot A3 needs (rung 2 confirming a rung-1 FAIL).
- `prior_findings` is duck-typed as `Sequence[Mapping[str, str]]` (code/where/
  detail keys) rather than importing `TableJudgeVerdict` from
  `socr.judge.table_verdict` (TICKET-A1, built concurrently in this same
  working tree) — A0 has no dependency on A1 per the ticket graph, and this
  keeps it that way; either module can land independently.
- Placeholder substitution (`str.replace`, not `str.format`) so the template can
  contain literal `{`/`}` in the JSON schema example without escaping.
