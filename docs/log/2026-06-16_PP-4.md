## Design decisions

**Inline mechanism**: parse the already-phantom-stripped `text` with `split_native_pages`,
augment per-page bodies in-memory, reassemble with `assemble_pages`. This avoids
re-introducing phantom refs from raw fragment files and is cleaner than re-stitching.

**Single authoritative fragment rewrite** (`_rewrite_all_fragments`): REVISE rounds 1–3
identified successive gaps:
- Round 1: figure-page fragments read from disk (pre-strip) + appended → fixed.
- Round 2: non-figure phantom pages kept raw fragments → rewrote ALL pages after figures.
- Round 3: figure-free docs with phantom refs skipped the rewrite (inside
  `_describe_and_embed_figures`, which early-returns when no figures) → moved the call.

**Final placement (round 3)**: `_rewrite_all_fragments` is called UNCONDITIONALLY from
`_phase_assemble`, after the `runs_figures` block, guarded by `if has_text:`. At that
point `final_text` is the truly-final body (post-strip, post-figures for figure docs;
plain post-strip for figure-free docs). `_describe_and_embed_figures` is now a pure text
transformer — it does not touch fragment files.

Unit tests that verify the fragment invariant call `_rewrite_all_fragments` explicitly
after `_describe_and_embed_figures`, mirroring `_phase_assemble`'s sequence.

**Vision engine lifecycle**: built ONCE per document, closed ONCE after the per-figure
loop. Explicitly tested.

**Doc-global numbering**: maintained by `FigureExtractor`. The orchestrator does not
re-number.

**Byte-identity for figure-free docs**: `_describe_and_embed_figures` early-returns `text`
unchanged; `_phase_assemble` then calls `_rewrite_all_fragments` which syncs all fragments
to the stripped body. PP-1 byte-identity invariant holds across all doc types.

**cap_page**: `FigureExtractor.extract` sets `cap_page = page_index + 1` (the first
unprocessed page) when breaking early. AuditEvent receives `extraction.cap_page or 0`.
