### Which case: the rescue became unreachable for its motivating case (remove)

The rescue (`_keep_when_stored_words_unusable` in `tables/source_evidence.py`, both
call sites in `verify_scanned_table`, `STORED_WORDS_UNVERIFIED_PREFIX`, and the
`stored_words_unverified` early accept plus structural gate in
`SourceEvidenceTableJudge.assess`) only runs when `native_trusted is False`. With
the distrust reverted, a rotated born-digital page reports True, so
`verify_scanned_table` defers to the native verifier and never reaches it. The only
remaining source of `native_trusted=False` is a page the born-digital detector
classifies as NOT born-digital (`is_born_digital=False`). That is a classifier
outcome, not proof of a scan: it also covers sparse or dirty text layers and
image-dominant pages, the GH-163 class. It is not the motivating case, and where keeping a model
table flagged on a layer nobody trusts is the fail-open direction GH-163 closed. I
did not invent another trigger.

The FOMC page-14 fixture (`/cursor/stores/...fomcminutes20190619.pdf`) does not
exist on this machine, so the two FOMC tests SKIPPED and were never run here; their
unreachability is argued from the trust flag and pinned by the new regression test,
not measured on that PDF. The other six tests in that file passed before removal,
but they force `native_trusted=False` by hand.

Removed: the rescue code above and `tests/test_rotated_no_stored_witness_table_keep.py`
whole (FOMC tests, the alpha-only P1 test, the structural-gate P2 test, the
unsupported-tokens tests of 51969bc). Findings 1 (P1) and 2 (P2) above no longer
have code to guard; they were correct for the code as it stood. Kept: orphan-drop
wording (finding 3 and its tests), hermetic `_resolve_judge_model` patches (4, 6),
sidecar assertion (6), comment fix (7).

Status: the rotated no-stored-witness rescue is WITHDRAWN pending a design that
does not distrust all rotated pages.
