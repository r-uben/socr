# #1405: the figure-caption leg

## Cause

`_describe_and_embed_figures` captions figures through `_get_vision_engine`. Four defects:

1. `OllamaFigureEngine` defaulted its host to a literal `http://localhost:11434` and never read
   `OLLAMA_HOST`, unlike every other Ollama caller (`resolve_ollama_host`, GH-222).
2. Its `/api/chat` payloads carried no `options.num_ctx`, so the daemon default sized the model.
   On a daemon whose default was 262144 the caption model took about 42 GB; at 32768, about 21 GB
   (64 GB Apple-silicon host, 2026-11-24).
3. `_try_gemini` handed out a bare `GeminiAPIEngine`. Its calls were outside `--max-paid-pages`,
   `--cost-budget` and the quota circuit, and nothing was written to `state.engine_runs`.
4. With `--qwen-backend vllm` captions still went to Ollama and then to the paid API;
   `VLLMEngine.describe_figure` existed and was never selected.

## Change

* **Host.** `OllamaFigureEngine(host=None)` resolves through `resolve_ollama_host`. An explicit
  host without a port now gets the daemon's port, as everywhere else; `test_gh968_total_deadline`
  keyed a draining probe by the port-less label and was updated.
* **Context window.** `FIGURE_NUM_CTX_DEFAULT` (32768, the window socr's vLLM recipe serves the same
  model with), overridable by `SOCR_FIGURE_NUM_CTX` or the constructor; sent in both `describe_figure`
  and `ask`. A malformed override falls back to the default. Not added to the caption identity:
  the run fingerprint already carries socr's source digest, and a window larger than the request
  does not change the output.
* **Paid fallback.** `GeminiAPIEngine.last_call_cost_usd` meters each call from the response's
  `usageMetadata` at the two rates the page price is built from (`providers.gemini_usage_cost_usd`):
  `0.0` when nothing was sent or the API refused, `None` when a request went out and its usage is
  unknown. `BudgetedPaidFigureEngine` wraps the engine; the orchestrator never hands it out bare.
  Before each call `_admit_paid_caption` checks the quota circuit, `--max-paid-pages` (one caption
  call counts as one paid page image) and `--cost-budget` (fail-closed on an unknown subtotal).
  After each call `_record_paid_caption` journals an `EngineResult` named `gemini-figure-caption`
  and charges the figure's page. A refused call sends nothing; the figure ships with
  `[figure description withheld: <reason>]` and a `figure_caption_paid_refused` event. The reasons
  are number-free so the mark survives the certified-floor caption check (#1266 round 7).
  `--strict-local` and a pinned zero cap still stop the engine from being built at all (GH-154).
* **vLLM tier.** When `qwen_backend == "vllm"` and the server lists exactly `qwen_vllm_model`
  (`VLLMEngine.serves_model`, full-id match as the vLLM judge's probe), captions go there first,
  with the gated paid engine as fallback. `LocalFirstFigureEngine` takes an `is_failure` predicate;
  for vLLM a caption counts only if it carries the caption marker. `_resolve_caption_engine_identity`
  returns `vllm:<model>` in that case. `auto` and `ollama` backends are unchanged.

## Limits

* `--cost-budget` is checked against spend so far. A caption's price is known only from its
  response, so the call that crosses the budget is made and the next is refused.
* `--max-cost-per-page` with a positive value is not applied to captions (no price before the call).
* `FigureInfo.engine` still records the composite's name (`local-first-figure`); which engine wrote
  a given caption is visible in the cost journal only when it was the paid one.
* A caption re-requested on resume is charged again; resume of figure captions is unchanged.
* The paid call's rates are those of `DEFAULT_GEMINI_MODEL`; a different `--gemini-model` is priced
  at the same rates, as the page reader is.
