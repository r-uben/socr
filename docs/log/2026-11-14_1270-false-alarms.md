## The split (coordinator ruling after the Astra and Carbon re-checks)

Classes 1, 2 and 3 remove a page's only mark without evidence that the shipped reading is complete: a dropped
`not` clears class 2, a truncated contents reading clears class 3, class 3 clears dropped columns, and class 1
freed 229 pages including one real defect. The rule is the one B1 (#1326) follows: **a mark may be removed only
when an independent page-scope check passed.** That check is C2's pass trace (#1332, not merged).

* This PR (#1325) ships **class 4 only**.
* Classes 1, 2 and 3, with their tests, the `unchecked_table_clauses` machinery that only served classes 2 and 3,
  the `layer_glyphs_undamaged` detector fact, the original full log and the measurement scripts, are preserved on
  `hold/issue-1270-b4-clearances` (pushed before the revert). They **wait for C2's pass trace** and are not lost.
* Reverted here: class 1 (`native_glyphs` span-level count, bullet note), class 2 (no-number clearance), class 3
  (shape-refused layer, `layer_refused_for_shape_alone`), `unchecked_table_clauses`, `layer_glyphs_undamaged`
  (nothing kept reads it). `born_digital.py`, `refinalize_own_text.py`, `tests/test_gh165_unresolved_math_outcome.py`
  and `tests/test_native_clean_pua.py` are `main`'s. `test_gh359_ladder_terminals.py` is `main`'s. The class 1 bullet
  note was dropped with class 1 (it was reachable only once the flag changed).

## What shipped: class 4

`FailureMode.WITNESS_DISAGREES` (witness read the page and disagrees) for `verifiable and not passed`;
`FailureMode.TABLE_UNVERIFIED_WITNESS` for `verifiable=False`. The second is a member of the
`table_unverified` family but not `TABLE_UNVERIFIED` itself: that mode is the table-judge ladder's
terminal and drives its retry and bucket logic, which the source-evidence gate must not enter.

Control flow is unchanged because every site that read `is HALLUCINATION` now reads
`result.WITNESS_REJECT_MODES = {HALLUCINATION, WITNESS_DISAGREES, TABLE_UNVERIFIED_WITNESS}`:
manifest 799/926/993/1032, the floor-cause helpers (`_floor_cause_is_contradiction`, the new
`_floor_cause_is_witness_unverifiable`), the ladder latch at ~12675. HALLUCINATION stays in the
set: old sidecars record it and fabricated image references still use it. The floor RECORDS the cause
in `manifest.py` (~5186) and `orchestrator.py` (`_apply_scanned_table_floor`); the scanned-table floor
latch (`"source_evidence_table" in att.reason`) is untouched, so `verifiable=False` still floors. The new
`PageState.scanned_table_witness_unverifiable` is DERIVED on resume from the persisted mode (no sidecar key,
as for its two siblings) and cleared with them. `_MODE_CLAUSES` names both: `source_evidence` FAIL and
UNKNOWN, instead of the `unknown=UNKNOWN` fallback (the legacy mode still falls there; so does
`no_witness_backend`, not touched here).

No new durable audit event, so `test_resume_restore_kinds.py` needed no change.
`_ESCALATION_MODES` and the scoreboard counters know the new modes.
