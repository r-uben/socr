## The split (coordinator ruling after the Astra and Carbon re-checks)

Classes 1, 2 and 3 remove a page's only mark without evidence that the shipped reading is complete: a dropped
`not` clears class 2, a truncated contents reading clears class 3, class 3 clears dropped columns, and class 1
freed 229 pages including one real defect. The rule is the one B1 (#1326) follows: **a mark may be removed only
when an independent page-scope check passed.** That check is C2's pass trace (#1332, not merged).

* This PR (#1325) ships **class 4 only**.
* Classes 1, 2 and 3, with their tests, the `unchecked_table_clauses` machinery that only served classes 2 and 3,
  the `layer_glyphs_undamaged` detector fact, the original full log and the measurement scripts, are preserved on
  `hold/issue-1270-b4-clearances` (pushed before the revert). They **wait for C2's pass trace** and are not lost.
* Reverted here: class 1 (`native_glyphs` span-level count, bullet note), class 2 (no-number clearance), class 3
  (shape-refused layer, `layer_refused_for_shape_alone`), `unchecked_table_clauses`, `layer_glyphs_undamaged`
  (nothing kept reads it). `born_digital.py`, `refinalize_own_text.py`, `tests/test_gh165_unresolved_math_outcome.py`
  and `tests/test_native_clean_pua.py` are `main`'s. `test_gh359_ladder_terminals.py` is `main`'s. The class 1 bullet
  note was dropped with class 1 (it was reachable only once the flag changed).

# B4 classes 1 and 3: true wording, no release (branch `fix/issue-1270-b4-release`, PR #1341)

Starts from `main` after C2 (#1332), C3 (#1338) and class 4 (#1325).

## Ruling (coordinator, after the Carbon, Fable and cubic reviews of the first version)

Text-layer and ink evidence cannot certify a page: a reading can ADD text, a layer can repeat a paragraph
(tealbook-partb 2018-05-02 p28), the ladder terminal is page-wide, and UNKNOWNs can be event-backed. So **no class
removes a mark or lifts a demotion in this PR.** The first version's release paths are deleted, with their code,
constants and tests: `private_use_bullets_released`, `native_coverage_outcome`, `independent_native_evidence`, the
class 2 no-number clearance (`_no_number_release`, `_every_layer_token_is_shipped`, the layer cleanliness test,
`numbers_clause_released`), the `layer_glyphs_undamaged` detector fact (read only by class 2), and
`unchecked_table_clauses`. The page-wide terminal question stays in #1334.

Claims were made true. Class 1 says nothing about maths fonts (the scan counted codepoints, and a page with
`has_math_font_typesetting` may typeset maths elsewhere) and does not say "not otherwise checked" (the pass trace may
hold a PASS or FAIL for another check). Class 3's agreement text states only what the numbers check did ("no check
covers what the reading omits"); it no longer says the page is "not otherwise checked", which is false on pages where
the table ladder, `row_binding`, the control-byte or prior-OCR checks also ran.

Class 2 (no-number pages) is not touched: its mark was already true ("ships no number to check").

## The unchecked-table mark: removed

`unchecked_table_clauses` was emitted only on a page whose numbers clause class 2 had released. With no release it
never fires, so it has no effect on any page. It is removed with its `_verdict_demotion_mode` and
`_status_is_explained` rows and its test file.
