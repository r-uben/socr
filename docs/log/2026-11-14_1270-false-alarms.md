# B4 classes 1-3 under the release rule (branch `fix/issue-1270-b4-release`)

Starts from `hold/issue-1270-b4-clearances` (the full pre-split B4) merged with `main` after C2 (#1332), C3
(#1338) and class 4 (#1325). Class 4 is `main`'s. The hold branch's classes 1-3 are re-built on C2's pass trace
under the **release rule** (coordinator, after the Astra and Carbon re-checks): a class may REMOVE a page's last
mark only when the page has independent page-scope evidence on the text it ships. Otherwise the mark stays and is
made TRUE.

* model-read page: `verdict.independent_page_evidence(trace, text)` (words check PASS at page scope, numbers PASS
  or NOT_APPLICABLE, no FAIL or UNKNOWN entry, every PASS digest-bound to the shipped text);
* native page: a digest-verified `native_coverage` (#1050 ink vs layer) PASS at page scope and no FAIL or UNKNOWN
  entry (`verdict.independent_native_evidence`). The entry is built in the release function and is NOT added to the
  persisted trace: adding it changes every native page's sidecar and fails the P6 byte-identity oracles
  (`test_p6_stage_ab_difference`, `test_p6_stage_c_difference`, five tests, seen red on the first attempt).

Two additions beyond the coordinator's text, each forced by a measurement or a reproduction:

1. **Class 2's every-token guard.** The words check ignores words under four letters, so Astra's dropped `not`
   passes it: with `words=PASS` the rule alone releases that page. The guard is a multiset test of all layer tokens,
   case-folded, against the shipped reading (a rewrapped hyphenation fails it and the page keeps its mark).
2. **Class 1's shipped-private-use veto.** Evidence rule alone, measured on run `51270eb5`: 195 native pages
   released, 5 of them hand-graded, **4 defective** (`tealbook-partb 2018-05-02 p28`, whose layer prints one
   paragraph four times; and `tealbook-parta` 2015-06-17 p11, 2019-10-30 p52, 2010-06-23 p32), 1 `other`. Ink-vs-layer
   cannot see a duplicated or mis-ordered layer. All 195 ship their bullets as raw private-use codepoints; #1005's
   rule ("a body that still carries private-use codepoints shipped the damage, whoever wrote it") is applied: no
   release while one ships. With the veto the 195 are reworded, not released.
