## Rule as built

Printed-line fragment merge, then boundary by indent test against `R_env` (local
environment), different-block lines also by pitch deviation from the modal pitch of the
size class. Hyphen: witness rejoin, hyphenated witness keeps, tie keeps, unwitnessed kept
as printed; glued hyphen/dash before a non-lowercase start (or any en/em dash) joins with no
space and removes nothing. No dictionary.

## Deviations and interpretation calls (read these)

1. **Indent reference is the column's left edge, not `a.x0`.** The verdict says
   `b.x0 > a.x0 + ws`. Taken literally an abstract never splits, so `R_env` would have
   nothing to fix and the (c) mutant could not fail. Built as `b.x0 > L_col + ws` (the
   prototype's `left + space` semantics); equal to the verdict's test whenever `a` sits at
   the left edge, which is every ordinary paragraph end.
2. **Constants.** `SIZE_CLASS_PT = 2.0` is the one fixed number (the panel's rounding for
   jittered OCR layers). A pitch needs at least two same-class observations (one cannot
   disagree with itself); fewer keeps the printed (block) boundary. Edges are the extreme of
   the best-populated single-linkage cluster (tolerance = word space); pitch is the lower
   median.
3. **Columns** are inferred: a run restarts when the baseline stops advancing or horizontal
   extent no longer overlaps; runs with the same left edge (within a word space) form one
   column group. Any run change is a boundary (column-break continuation stays split).
4. **Table pages:** a paragraph is found only if ALL its lines are in the shipped text
   verbatim, so a paragraph with a table cell or a spliced link in the middle is left as
   printed. Conservative; no measurement of how often.
5. **Protected lines** = CommonMark literal context (`chart_regions.markdown_literal_context`:
   fences, code, HTML blocks/comments), any line with `|`, `![`, `$$`, `\[`, `\]`,
   `\begin{`, `\end{`. Inline `$` (currency) is NOT protected: it would exclude most economics
   prose.
6. **The geometry-shape test uses one size class per pitch.** (b) is 13pt so its pitch
   (22 > 1.5x) does not share a median with (a)'s 12pt pitch. Mixed pitches in one size class
   on a page would be a different (unmeasured) case.
7. Mutant tests mostly fail in `test_geometry_reads_five_paragraphs...`, a single
   whole-shape assertion; I did not confirm per mutant that the diff lands in the intended
   shape beyond the construction argument.

## Review round 1: font change alone is not a boundary

`boundary()` returned True on any change of the line's longest-span font, so an italic phrase
split a sentence (Ayivodji p7 "Ottawa" / "Citizen"). Now a font change counts only when the
previous line ends short of `R_env` (a heading). Font-decided boundaries before -> after:
Ayivodji 94 -> 2, Ozdagli-Weber 118 -> 37, Nakamura-Steinsson 52 -> 20 (paragraph count with
the bare test minus the count with fonts ignored). Of 5 removed spot-checked: 4 mid-sentence
splits correctly merged (Ayivodji p5, p7, p12 x2); 1 real break wrongly merged (Ayivodji p2,
a quote followed by its attribution line). Removed ones on Ozdagli p9 are display-equation rows
merging (accepted residual). Tests: italic-across-line and short-line-before-bold-heading
(`_font_page`); mutants bare-font-test and font-ignored both fail it.

## Review round 2 (Astra)

- P0 protected interiors: `_protected_lines` now scans comment / `$$` / `\\[` / `\\begin` ranges
  token by token and protects every line they touch, interior included (a range opening and
  closing mid-line protects that line only). Unterminated ranges protect to the end.
- P1 idempotence: `reflow_native_prose` verifies its result is a fixed point (a second pass
  changes nothing) and otherwise ships the text as printed. Chosen over arguing the collision
  cannot happen or reworking matching: it is a local, checkable guarantee, and the fallback is
  stable (`reflow(x) == x` falls back again). Cost: a second pass per finalize. Tested at
  function level with the exact `alpha|beta` + `alpha beta|gamma` example; a PDF that makes
  real geometry collide is contrived and I did not build one, so resume of such a page is
  covered by the fixed-point property, not by an e2e.
- P3 identity tests: final `.md` and replay equal `assemble_pages([body])` exactly, the
  sidecar `winning_output.text` equals the body. Mutant `replay-emits-twice` fails.
- Mutants `no-interior-protection`, `no-fixpoint-check`, `replay-emits-twice` all fail their tests.
- Ayivodji vs main after both rounds: 63 pages changed, only `-` removed (159), 0 added.

## Review round 3: fail-closed math span, resume actually resumes

- The range scanner is replaced. If the text has any marker (`$`, `\\(`, `\\)`, `\\[`, `\\]`, `\\begin{`,
  `\\end{`, `<!--`, `-->`, a code fence), EVERY line from the first marker line through the last is
  protected; reflow still runs above and below. Pairing logic leaked on unbalanced, nested,
  mismatched and multi-line-inline shapes. Protected lines are never joined in either direction
  (a LaTeX `%` would comment out its successor). Known limit of the rule as specified: lines
  AFTER the last marker reflow even if an environment was never closed.
- Cost on real native pages (both runs native): Ayivodji 0 of 66 pages carry a marker,
  Ozdagli-Weber 1 of 56, Nakamura-Steinsson 0 of 45. Ayivodji vs main: only `-` removed (159).
- Resume test spies `_load_terminal_page` and asserts it served page 1; mutant
  `terminal-never-loads` fails it. Sidecar equality is byte-for-byte (no `.strip()`).
