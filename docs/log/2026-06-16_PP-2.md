# PP-2 — Agentic loop page-major + per-page provisional flush + cascade-halt

**Date**: 2026-06-16
**Ticket**: PP-2 (GH-71)
**Branch**: feat/71-pp2-agentic-fuse

## What changed

### `src/socr/pipeline/orchestrator.py`
- Added module-level imports: `route_page` from `socr.pipeline.agentic` and
  `probe_ollama_idle` from `socr.tables.extract` (both at module scope for patchability
  in tests).
- `_flush_page_sidecar`: added `terminal: bool = True` kwarg; payload now includes
  `"terminal": terminal` field.
- Phase 4c gate in `process()`: `dual_pass_tables` skipped when `agentic and not is_multi`.
- `_TimeoutJudge` inner class: ThreadPoolExecutor-based wall-clock guard for the
  `PageJudge.assess()` call; returns `AcceptDecision(accept=False, reason="judge timeout")`
  on expiry.
- `_phase_agentic` complete rewrite: single fused all-pages loop over `sorted(state.pages)`.
  - Native pages: `PageOutput(engine="native")` created, `ps.best_output` set, flushed
    as provisional fragment + sidecar (`terminal=False`).
  - OCR pages: `route_page` called; `_reread_page_tables` per OCR page; equations
    (default-off behind `enable_equation_detection` / `enable_equation_latex` flags).
  - Cascade-halt: timeout-in-attempts + `not probe_ollama_idle()` → set
    `backend_degraded=True`, emit `partial_save_vlm_timeout` AuditEvent, then break
    on next OCR page (native pages always proceed).
  - Halt reason stored in `state._pp2_halt_reason`.
- `_phase_assemble`: propagates `state._pp2_halt_reason` into `final_result.error`.

### `tests/test_pp2_agentic_fuse.py` (new, 15 tests after REVISE)
- `TestByteIdentity`: golden test (`test_final_md_matches_golden`) locks exact assembled
  bytes byte-for-byte against a pre-computed golden string for a 3-page fixture
  (p1/p3 OCR via patched `route_page`, p2 native); `test_determinism_two_runs_identical`
  runs the same fixture twice and asserts identical `result.markdown`.
- `TestIncrementalFlush`: all pages (native + OCR) get fragments + sidecars; provisional
  sidecars carry `terminal=False`.
- `TestPhase4cGate`: dual-pass tables skipped in agentic, runs in non-agentic.
- `TestCascadeHalt`: backend-degraded halt path asserts `pages/00001.md` on disk +
  `audit_log.json` present + `partial_save_vlm_timeout` event unconditionally; healthy-backend
  no-halt path.
- `TestEquationFlagsOff`: equation detection/latex skipped with default flags.
- `TestJudgeBuiltOnce`: judge built exactly once for N pages.
- `TestTimeoutJudge`: slow judge returns timeout-reject; fast judge passes through;
  `None` timeout bypasses executor.

## Design decisions

- **Fork A (assemble-authoritative)**: provisional fragments are crash-recovery only;
  `_rewrite_all_fragments` in `_phase_assemble` is the sole authoritative writer.
  Byte-identity preserved because the final write path is unchanged.
- **Fork C2**: `_phase_analyze` stays doc-wide; fuse only route→tables→equations→flush
  into the one all-pages loop (not _phase_analyze).
- **Fork B (judge-guard)**: `_TimeoutJudge` stays in `orchestrator.py` — no changes to
  `agentic.py`, within write-ownership.

## Deviations / follow-up

- Equation flags (`enable_equation_detection`, `enable_equation_latex`) are wired into
  `PipelineConfig` but not yet in YAML/CLI. A future ticket can expose them.
- `_TimeoutJudge` timeout (`_judge_timeout`) is derived from
  `max(provider_timeout.values())` where `provider_timeout` defaults to
  `DEFAULT_PROVIDER_TIMEOUTS` (`{QWEN: 300s, GEMINI: 240s}`) — so the guard is
  **active at 300 s by default** (the max across all configured providers).  It is
  only `None` when `provider_timeout` is explicitly set to an empty mapping.
