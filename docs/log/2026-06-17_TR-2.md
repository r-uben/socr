## What changed

### 1. Chart-clip: `_collapse_header_prefix` + `_DATA_VALUE_RE` in `reconstruct.py`

Added `_DATA_VALUE_RE = re.compile(r"-?\d+\.\d+")` — a decimal-float pattern used to
distinguish header rows (which have indicator names and year labels, never decimal numbers
like "2.1") from data rows. Added `_is_header_row(row)` and `_collapse_header_prefix(grid)`.

`_collapse_header_prefix` detects multi-line header prefixes (rows at the top of a segment
that contain no decimal values in data columns) and merges them column-by-column. For the
CE-like fixture's two-line header:

    Row 0: | GDP | GDP | CPI | CPI |   (indicator names at y≈54)
    Row 1: | Forecaster | | | | |     (label column name at y≈60)
    Row 2: | 2024 | 2025 | 2024 | 2025 |  (year names at y≈64)

→ collapsed to: `| Forecaster | GDP 2024 | GDP 2025 | CPI 2024 | CPI 2025 |`

Called in `rowize_from_word_list` after `_clean_grid`.

Also removed the unused `import fitz` guard from `rowize_from_words_chart_aware` (ruff F401).

### 2. Chart region PNG rendering: `_render_chart_region_pngs` in `orchestrator.py`

Added `_render_chart_region_pngs(pdf_path, page_num, native_text, figures_dir)` method. When
a born-digital table page's OCR fails and `native_table_structure_failed = True`, if
`ps.native_text` contains `chart_region_p{page_num}_{i}.png` placeholders (from
`rowize_from_words_chart_aware`), this method:

1. Opens the PDF page and calls `chart_region_bboxes(page)` to get the same bboxes the
   rowizer used when generating the placeholders.
2. Renders each bbox as a cropped PNG with `page.get_pixmap(matrix=mat, clip=bbox)`.
3. Saves to `figures_dir` (= `doc_dir / "figures"`).
4. Returns updated `native_text` with `figures/chart_region_p{N}_{i}.png` paths so
   `strip_phantom_images` (called in `_phase_assemble` with `output_dir=doc_dir`) finds the
   files and preserves the image ref.

On any render failure: returns `native_text` unchanged (fail-open: the placeholder is stripped
as before; the audit records the failure via the existing phantom-image stripping path).

Called right after `ps.native_table_structure_failed = True` in `_phase_agentic`.

## Review revision (socr-reviewer → fixes)

socr-reviewer returned REVISE. Three changes applied (the implementer agent died after writing
the edits but before running tests / committing; the orchestrator verified, documented, and
amended).

1. **BLOCKING — silent content loss in `_collapse_header_prefix` (reconstruct.py).** The old
   `_is_header_row` classified ANY row with no decimal value (`\d+\.\d+`) in cols 1+ as a header,
   so a legitimate all-`na` forecaster row or an integer-only row could be swallowed into the
   header prefix and LOST. Rewrote `_is_header_row`: a row is header-safe ONLY if (a) col 0 is
   empty (pure column-metadata row like `['', 'GDP', 'GDP']`) or (b) col 0 is non-empty but ALL
   data cells are empty (the label-column-name row like `['Forecaster', '', '', '']`). Any row
   with a name in col 0 AND a value in any data cell is a data row, never a header. Two regression
   tests added in `tests/test_reconstruct.py` (`test_all_na_data_row_not_swallowed`,
   `test_integer_only_data_row_not_swallowed`); the all-`na` test is verified to FAIL on the
   pre-fix code and PASS after.

2. **Per-region verifier wired (diagnostic).** `verify_native_table_region` was previously dead
   code. Wired via `_verify_regions` in `born_digital.py`, called at the extraction point where
   both region bboxes and per-region text are available: it clips `get_text("words")` to each
   table region's bbox and runs the geometry check against that region's OWN lanes, avoiding the
   whole-page false `geometry_impossible_collapse`. **Honest scope note:** this is a *diagnostic /
   warn* step at born-digital extraction, NOT a gate. The agentic-path whole-page verifier
   (`agentic.py:~405`, on the VLM output path) is NOT yet converted to per-region — that rework
   belongs to **TR-3** (which reworks the verifier→selection / D3 flow). v1's CE path is
   born-digital, so the diagnostic placement covers the in-scope case.

3. **Over-segmentation upper-bound guard** added to `assert_table_parity`: an over-split
   (rowizer fragments one table into many) now fails the parity gate (`max_tables =
   len(table_regions) + 1`), restoring the upper bound lost when `test_tr1_rowizer` relaxed
   `== 1` → `>= 1`.
