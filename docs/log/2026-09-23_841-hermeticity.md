# GH-841 — the AUTO-engine probe hides in tests (2026-09-23)

## Reproduced

`tests/test_gh159_provider_identity.py::test_the_agentic_loop_hands_the_profile_down_to_the_engine_runner`:
**0.29s** with ollama up, **7.33s** with `OLLAMA_HOST=127.0.0.1:1`. `PipelineConfig.primary_engine`
defaults to `AUTO`, so `process()` calls `resolve_auto_engine()`, which builds engines from the
registry directly (not through `get_engine`) and shells out to `ollama`. After pinning
`primary_engine` / `local_engine` / `enabled_engines`: 0.29s with ollama unreachable.

## How many other tests share it

scale — it sat on network timeouts for over half an hour. Instead,
`2026-09-23_841_probe_recorder.py` (a pytest plugin, loaded with `-p`) wraps
`resolve_auto_engine` / `resolve_local_engine` in both `registry` and `orchestrator` (which
imports it by name) and records which test called it. One normal-speed run:
