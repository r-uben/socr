# TICKET-A1 — Provider identity = engine + backend + model

Date: 2026-06-14

## What changed

### `src/socr/core/providers.py`
- Added `id: str`, `backend: str`, `model: str`, `auto_eligible: bool = True` fields to `ProviderProfile` (frozen dataclass).
- Defined 10 named module-level profile constants: `PROFILE_QWEN_LOCAL`, `PROFILE_QWEN_CLOUD`, `PROFILE_GEMINI`, `PROFILE_MARKER`, `PROFILE_GLM`, `PROFILE_NOUGAT`, `PROFILE_MISTRAL`, `PROFILE_DEEPSEEK`, `PROFILE_DEEPSEEK_VLLM`, `PROFILE_VLLM`.
- `PROFILE_MISTRAL` and `PROFILE_DEEPSEEK` have `auto_eligible=False` — excluded from the default ladder.
- `DEFAULT_PROVIDERS` updated to use the named profile constants (EngineType keys unchanged — existing code keyed on EngineType still works).
- `provider_ladder()` gained `include_ineligible: bool = False` parameter. Without it, `auto_eligible=False` profiles are filtered out.
- Added docstring clarifying the provider identity design decision.

### `src/socr/pipeline/agentic.py`
- Added `provider_id: str = ""`, `model: str = ""`, `backend: str = ""` fields to `ProviderAttempt` dataclass.
- Both `ProviderAttempt` constructions in `route_page` (normal path and exception handler) now wire `provider_id=prof.id`, `model=prof.model`, `backend=prof.backend`.

### `tests/test_providers.py`
- Updated `test_ladder_is_cheapest_first`, `test_free_engines_tie_broken_by_priority`, `test_none_available_means_all_known`, `test_max_cost_per_page_cap` to pass `include_ineligible=True` where they need DeepSeek/Mistral.
- Added `PROFILE_QWEN_LOCAL` import.
- Added 3 new tests: `test_profile_has_id_backend_model`, `test_auto_eligible_filters_ladder`, `test_include_ineligible_shows_all`.

### `tests/test_agentic.py`
- Fixed module-level `LADDER` constant to pass `include_ineligible=True` (MISTRAL is now `auto_eligible=False`).
- Added `test_provider_attempt_records_id_model_backend`.

### `tests/test_p1_cascade_economics.py`
- Added `include_ineligible=True` to `FULL_LADDER` call so cascade reachability tests continue to include DeepSeek and Mistral.

## Test result
- Target tests: 44 passed.
- Full suite: 714 passed (up from 710 pre-ticket; 4 new tests added).

## Deviations / follow-up
- `PROFILE_QWEN_CLOUD` is defined but has no `EngineType` key in `DEFAULT_PROVIDERS` — `EngineType.QWEN` maps to the local-instruct profile. The cloud variant is accessible as a named constant for future use (TICKET-B2 or explicit override). This was the right call: both variants share the same `EngineType.QWEN` enum value.
- `orchestrator.py` `_available_engines_for_agentic` is unchanged: it still uses `DEFAULT_PROVIDERS` keyed by `EngineType`, returns `set[EngineType]`, and the `provider_ladder()` call there does not pass `include_ineligible=True` — meaning DeepSeek and Mistral are automatically excluded from agentic routing (B1's goal, already achieved by A1's `auto_eligible=False` default).
- `gemini-1.5-flash` is a placeholder model name in `PROFILE_GEMINI`; the actual model is wired in the Gemini engine. The field is for manifest/replay identity, not routing logic.
