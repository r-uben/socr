# TICKET-B2 — Agentic as default mode

**Date:** 2026-06-14
**Status:** DONE
**Tests:** 728 passed (12 new in test_b2_routing.py, +3 guard fixes in canon test files)

## What changed

### `src/socr/core/config.py`
- `PipelineConfig.agentic` default changed from `False` to `True`; comment updated to note
  `--legacy-routing` as the opt-out path.
- New field `strict_local: bool = False` — when `True`, the agentic ladder is filtered to
  local/free rungs only (no cloud escalation).

### `src/socr/cli.py`
- `common_options`: added `--legacy-routing` (is_flag, sets `agentic=False`) and
  `--strict-local` (is_flag, sets `strict_local=True`) flags.
- `build_config`: added `legacy_routing: bool = False` and `strict_local: bool = False`
  params; wired with precedence: `legacy_routing` beats explicit `--agentic`.

### `src/socr/pipeline/orchestrator.py`
- `_phase_agentic`: after `available = self._available_engines_for_agentic()`, added
  `if self.config.strict_local: available = [p for p in available if p.is_free]` to
  drop cloud rungs when `--strict-local` is set.
- `_run_fingerprint`: added `"strict_local": cfg.strict_local` to the `extra` dict so
  toggling `--strict-local` invalidates the resume cache.

### `tests/test_b2_routing.py` (new)
12 tests covering:
- `PipelineConfig().agentic is True`
- `PipelineConfig().strict_local is False`
- `build_config(legacy_routing=True)` → `agentic=False`
- `build_config(agentic=True, legacy_routing=True)` → `agentic=False` (precedence)
- `build_config(strict_local=True)` → `strict_local=True`
- `_phase_agentic` with `strict_local=True` passes only `is_free` profiles to `provider_ladder`
- `_phase_agentic` with `strict_local=False` passes all profiles
- `strict_local` change produces different `_run_fingerprint`
- CLI `--help` shows `--legacy-routing` and `--strict-local`

### `tests/test_orchestrator.py`
- `_make_config` now defaults `agentic=False` so the many existing deterministic-pipeline
  tests continue to test the backbone/score/repair path, not agentic routing.

### `tests/test_canon_round2.py` / `tests/test_canon_round3.py`
- `_config` helpers now default `agentic=False` (same reason as above).
- `test_limit_batch_without_o_persists_output` CLI invocation updated to pass
  `--legacy-routing` since it patches `_phase_backbone` (which is bypassed in agentic mode).
