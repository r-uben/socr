# Log: TICKET-C2 — Local-first figure description

**Date:** 2026-06-14
**Status:** DONE (revised after review — added per-call fallback)

## What changed

### `src/socr/engines/gemini_api.py`
Added two new classes after `GeminiAPIEngine`:

**`OllamaFigureEngine`**
- `__init__(model, host)` — defaults to `qwen3-vl:30b-a3b-instruct` at `http://localhost:11434`
- `is_available() -> bool` — `GET /api/tags` with 3 s timeout; checks exact model name in list
- `describe_figure(image, figure_type, context) -> FigureInfo` — posts to `/api/chat` with
  base64 JPEG image; returns `FigureInfo(engine="ollama-figure")`; on any exception returns
  a FigureInfo with `"Ollama figure error: ..."` prefix in description
- `close()` — no-op (stateless HTTP)

**`LocalFirstFigureEngine`** (composite, addresses reviewer finding: per-call fallback)
- Wraps `OllamaFigureEngine` + optional `GeminiAPIEngine`
- `describe_figure`: calls Ollama; if description is non-empty and does not start with the
  error prefix, returns it; otherwise falls back to Gemini (if configured); if Gemini also
  absent, returns the Ollama result as-is
- `close()`: delegates to both sub-engines

### `src/socr/pipeline/orchestrator.py`
Rewrote `UnifiedPipeline._get_vision_engine()` for local-first routing:
1. When Ollama is available: build a `LocalFirstFigureEngine(ollama, gemini_fallback)` where
   `gemini_fallback` is a `GeminiAPIEngine` (if GEMINI_API_KEY is set and reachable) or None.
   This gives per-call fallback to Gemini on empty/error, as the ticket requires.
2. When Ollama is unavailable: fall back to `GeminiAPIEngine` directly (existing path).
3. When both unavailable: return None (same graceful degradation as before).

### `tests/test_gemini_api.py`
Added five new test classes (21 new tests, 33 total):
- `TestOllamaFigureEngineIsAvailable` — model present/absent, non-200, connection error (4)
- `TestOllamaFigureEngineDescribeFigure` — happy path, RGBA conversion, error path, name (4)
- `TestLocalFirstFigureEngine` — Ollama success (no Gemini call), empty fallback, error fallback,
  no-gemini error, name property, close delegates (6)
- `TestGetVisionEngineFallback` — Ollama unavailable → GeminiAPIEngine; Ollama available →
  LocalFirstFigureEngine; available + key → Gemini attached; both down → None (4)
