Worked example. Every cell of this table has been filled in with its own
reference, so each one shows exactly which position it names:

| H1C1 | H1C2 | H1C3 |
| --- | --- | --- |
| R1C1 | R1C2 | R1C3 |
| R2C1 | R2C2 | R2C3 |

The same on a narrower table. Nothing about the numbering depends on what a
column holds, so the leftmost column is `C1` here too:

| H1C1 | H1C2 |
| --- | --- |
| R1C1 | R1C2 |

And on a table whose header spans two levels, the upper header row is `H1` and
the lower one `H2`, while the body rows are still counted from the first row
below the whole header:

| H1C1 | H1C2 | H1C3 |
| H2C1 | H2C2 | H2C3 |
| --- | --- | --- |
| R1C1 | R1C2 | R1C3 |
